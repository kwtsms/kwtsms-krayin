# Changelog

## [1.0.0] - Unreleased

### Added

- "Send SMS to person" workflow action for lead and person workflows, with Krayin placeholders.
- kwtSMS section in Settings > Configuration (API login, Sender ID, test mode).
- The API password is stored encrypted and never shown again on the settings page.
- Tested on Krayin 2.2.0 (PHP 8.3): a person workflow sent the SMS with test=1.
